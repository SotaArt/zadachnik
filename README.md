# 📋 Задачник

Офлайн-приложение для личных задач, хронометража рабочего времени и контроля
менеджеров (КМ): сессии, фиксация звонков, ежедневная отчётность.

Полностью клиентское: **один HTML-файл**, без сервера, без зависимостей, без
регистрации. Все данные хранятся локально в браузере (`localStorage`), с
автосохранением в файл (Chrome/Edge) и JSON-экспортом для бэкапа.

## 🚀 Онлайн

Приложение опубликовано на GitHub Pages:

**https://sotaart.github.io/zadachnik/**

> При открытии по новому адресу старые локальные данные не переносятся
> автоматически — они привязаны к origin. Перед переездом сделайте
> **Экспорт** из старой версии и **Импорт** в новой.

## 🧩 Возможности

- **Задачи**: сроки, напоминания, повторы (ежедневно / по будням / еженедельно /
  ежемесячно), фильтры, поиск, статистика.
- **Моё время**: таймер в реальном времени, ручной ввод, норма 8 ч, расчёт
  неучтённых интервалов в рабочем окне 9:00–18:00, отчёты.
- **Сотрудники / сессии с КМ**: таймер сессии и звонка, метки «есть диалог» /
  «отказ», ОС по звонку, заметки, история и отчёты (`.txt` / `.csv`).
- **Итог дня**: единый отчёт по срезу дня, задачам, времени и каждому КМ.
- **PWA**: установка на телефон, работа офлайн (service worker).

## 💾 Данные и бэкапы

- Ключи хранилища фиксированы (`tasker_data_v1_*`) и не меняются при обновлении кода.
- Три уровня защиты: автосохранение в `localStorage`, автосохранение в файл
  (Chrome/Edge), ручной **Экспорт** JSON.
- Для надёжности делайте JSON-бэкап регулярно — браузер может очистить
  `localStorage`.

## 🛠 Локальный запуск

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер,
чтобы протестировать PWA/service worker:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## 🌐 Деплой на GitHub Pages

1. Загрузите файлы в репозиторий (ветка `main`).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Требуется HTTPS — service worker и установка PWA работают только на HTTPS или
`localhost`.

## 🔒 Приватность

Вся информация хранится на устройстве пользователя и не отправляется на серверы.
Не коммитьте в репозиторий файлы бэкапов с персональными данными (эти паттерны
внесены в `.gitignore`).
